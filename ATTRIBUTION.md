# Attribution

The Palestine databank served **205,118 observations** spanning **1922-01-01 to 2026-08-07** from the sources below when this file was last generated (2026-08-08). Every row carries its source and licence in the API response; this file is the same information in one place.

> Generated from the database by `ops/gen_attribution.py`. Do not edit by hand — a hand-maintained credits file breaks silently the first time a source is added and nobody remembers.

> **Hand-corrected 2026-09-25, and why that broke the rule above.** The 2026-08-08 generation filed IODA (All Rights Reserved), OONI and WHO (both non-commercial share-alike) under "Redistributable, commercially or otherwise", and the HDX rows under "terms unread" — the licence records had moved on the same day (migrations 065 and 067) and nothing has run the generator since. Worse, the generator itself groups by `redistribution` alone, so a fresh run would print non-commercial sources under a heading that says they may be used commercially. The sections below are keyed on what each licence obliges — `redistribution` AND `commercial_use` — and every licence string, grade and attribution text was re-read from the `source` rows those migrations set (050, 053, 058, 063–067). **Row counts are still the 2026-08-08 figures** (a count needs production data); regenerate on main-server once the generator is fixed, and this note goes away with the hand edit.
