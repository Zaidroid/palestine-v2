أضف نفس الرابط كخادم MCP بعيد (streamable HTTP). العميل اللي بيعرف OAuth بيوصل لصفحة المفتاح لحاله؛ واللي بياخد رابط بس:

Add the same URL as a remote MCP server (streamable HTTP). A client that speaks OAuth finds the key page by itself; one that takes only a URL can carry the key in it:

__BASE__/mcp?key=__KEY_OR_PLACEHOLDER__

curl

# REST — no key
curl '__BASE__/v2/checkpoints/status?name=Qalandia'

# MCP — with a key
curl -s -X POST __BASE__/mcp \
  -H 'X-Api-Key: __KEY_OR_PLACEHOLDER__' -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"checkpoint_status","arguments":{"name":"قلنديا"}}}'
