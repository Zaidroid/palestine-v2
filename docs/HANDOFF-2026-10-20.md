## How this lane works

- DB writes only through a command script Zaid runs (`tmp/NN-*.sh`, which stops at the first failure). Read with `SET default_transaction_read_only = on`.
- A migration creates any unit it uses; the registry runs after the migrations. `ALTER TYPE … ADD VALUE` is its own migration.
- Loaded rows are not served until a question reaches them: check with the API after the command runs.
- Archive questions go through `ops.ask_archive`, never ILIKE over bodies.
- A DeepSeek "keep" is a candidate, not a row. When its bar is "the subject matches", re-read every row, not a sample.
- Ledger: one line per command that ran, in `docs/PLAN-2026-09-24-PUBLIC-RELEASE.md` §11.
- The classifier refuses bulk deletes, prunes, killing processes and reading v1 code: hand those to Zaid as commands.
